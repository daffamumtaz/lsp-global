# Audit antislop seluruh halaman

Tanggal: 30 September 2026. Mode: after, pilihan pengguna dalam sesi ini.
Status: audit selesai; perubahan UI menunggu ACC nomor temuan. Hanya laporan ini ditambahkan.

## Cakupan dan bukti

- Kode seluruh delapan jenis halaman dibaca: Beranda, Tentang Kami, katalog skema, detail skema, Informasi, Galeri, Mitra, Kontak; termasuk komponen bersama, CSS, dan sumber datanya.
- HTTP 200 dan satu H1 ditemukan pada `/`, `/tentang-kami`, `/skema-sertifikasi`, `/skema-sertifikasi/junior-coder`, `/informasi`, `/galeri`, `/mitra`, `/kontak`.
- `/skema-sertifikasi?q=junior` menghasilkan satu hasil Junior Coder dalam HTML. Kedua SearchField sudah memakai form GET menuju katalog. Audit lama yang menyebut pencarian belum berfungsi tidak lagi sesuai kode saat ini.
- Fragmen lokal `#...` pada HTML yang diambil semuanya memiliki target. Ini tidak membuktikan fokus/scroll aktual browser.
- `node --test src/lib/*.test.mjs`: enam file tes lulus, nol gagal. Ini tes logika, bukan tes visual atau klik UI.
- Screenshot pengguna menjadi bukti visual footer/header Kontak saja. Inventaris browser kosong, dan in-app browser tidak tersedia. Tidak ada klaim pengujian klik, keyboard aktual, computed layout, zoom 200%, atau viewport 375/768/1440.
- Tidak ditemukan DESIGN.md di proyek. Arah yang dipertahankan pada usulan: logo dan palet biru LSP, tipografi serta komposisi yang sudah ada. Tidak ada usulan rebranding atau aset buatan.
- HIGH = Hard Gate; MEDIUM = Purpose-Gate; LOW = Quality Locks. Temuan yang bersifat risiko atau membutuhkan konfirmasi konten disebut eksplisit.

## Yang dipertahankan

- Search menuju katalog, hasil/filter/reset dan URL state sudah ada; tidak perlu membangun mesin pencarian baru.
- Skip link, focus-visible, label form, target navigasi, menu Escape/outside click tersedia dalam kode.
- Viewer Galeri memakai dialog native dengan kontrol tutup dan pemulihan fokus; bagan menyediakan alternatif daftar.
- Empty state katalog, galeri video, direktori, struktur dan halaman Mitra sudah ada.
- Card skema memakai flex column dan aksi margin-top auto; pola ini bisa digunakan saat merapikan card review.
- Background overlay hero membantu keterbacaan; grid card katalog membantu membandingkan skema. Keduanya punya fungsi, bukan otomatis pelanggaran karena pola umum.
- Warna merek dan logo LSP dipertahankan. Audit tidak meminta toggle dark mode, animasi, atau penambahan library UI.

## Gate dan batas kelulusan

- Hard Gate FAIL — ada kontras 4.387:1 (5), konten contoh tanpa penanda menyeluruh (6–9), status error/empty yang kurang (10,12), dan sosmed menyerupai kontrol tanpa tautan (11).
- R-24 PASS terbatas pemeriksaan server — delapan jenis rute 200 dan fragmen lokal valid; klik navigasi aktual belum diuji.
- R-32 UNVERIFIED — dukungan keyboard/fokus terlihat di kode; belum ada uji Tab/Enter/Escape melalui browser.
- R-35 UNVERIFIED untuk UI — server dijalankan dan halaman diambil, tes logika lulus; build serta click-through tidak dilakukan pada audit read-only ini.
- Purpose-Gate NEEDS REVIEW — ikon brand perlu konsistensi (1), tipografi paragraf perlu perbaikan (4). Tidak ditemukan kebutuhan menghapus seluruh motif merek atau bayangan berdasarkan bukti yang ada.
- Liveliness UNVERIFIED — belum ada DESIGN.md/dial resmi dan observasi visual seluruh halaman. Usulan terbatas pada konsistensi komponen; tidak mengklaim redesign lolos gate.
- Quality Locks FAIL — search, padding card, gap dan tepi container belum seragam (2,3), keterbacaan belum konsisten (4).
- C-5 FAIL — asal data contoh dan rating tidak cukup jelas kepada pengguna (6–9).
- Tidak ada perubahan UI yang diklaim selesai atau lolos gate. Setelah ACC, gate untuk cakupan yang disetujui perlu diperiksa kembali.
