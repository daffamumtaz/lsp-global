# Audit dan rencana UI LSP TIK Global

## Pembaruan implementasi dan SSH

Pembaruan berikutnya pada sesi yang sama memperluas perubahan ke sistem tipografi lintas halaman: token display/heading/metadata/kode, Figtree sebagai satu-satunya font web yang dimuat, judul kartu skema mengikuti token subheading, angka statistik 32–48 px berbobot 700, dan monospace sistem untuk kode unit kompetensi. Inter dan Plus Jakarta Sans dihapus dari pemuatan. Tidak memasang Nerd Font.

Target SSH: alias `neuralia`, aplikasi `/var/www/lsp-global-staging/frontend`, service `lsp-global-staging-frontend.service`, URL path `/lspglobal/public`. Patch diterapkan pada salinan sumber server agar penyesuaian basePath dan publicAsset tetap terjaga. Build memakai webpack; konfigurasi environment dan database tidak diubah.

Backup reversibel:

- Sumber sebelum perubahan: `/var/www/lsp-global-staging/typography-backup-20261029/source-before.tar.gz` dan `chrome-partners-before.tar.gz`, dengan checksum sumber.
- Build lama: `/var/www/lsp-global-staging/frontend/.next.before-typography-20261029`.
- Rollback: jalankan `sudo bash /var/www/lsp-global-staging/typography-backup-20261029/rollback.sh` melalui SSH. Skrip menghentikan service, menyimpan build baru terpisah, memulihkan build/sumber lama, menyalakan service, dan memeriksa HTTP. Skrip hanya dipakai sekali per backup build; file tambahan yang tidak lagi direferensikan tidak memengaruhi versi lama. Skrip diperiksa sintaksnya, belum dieksekusi untuk rollback nyata.

Investigasi animasi Zen/Linux:

- Pembacaan sistem lokal menemukan GNOME `enable-animations=false`, GTK `gtk-enable-animations=false`, dan KDE `AnimationDurationFactor=0`. Tidak ditemukan override reduced motion pada preferensi Zen yang diperiksa. Ini mendukung dugaan Zen mewarisi reduced motion; pengujian langsung pada mesin Zen belum dilakukan.
- Pengujian browser dengan emulasi `prefers-reduced-motion: reduce` mereproduksi gejala: hover kartu tidak scale dan kedua carousel tidak autoplay. Ini perilaku yang diprogram, bukan bukti aset animasi gagal diunduh.
- Ditambahkan kontrol footer: “Aktifkan animasi” untuk opt-in khusus situs, atau “Ikuti pengaturan perangkat” untuk mengembalikan default. Pilihan disimpan di localStorage, dengan fallback sesi saat storage tidak tersedia. Tidak mengubah pengaturan Linux/browser.
- Autoplay tetap berhenti saat tab tersembunyi, fokus berada dalam carousel, atau pengguna menekan jeda. Hover hanya menghentikan autoplay pada perangkat berpointer halus yang mendukung hover, menghindari hover sentuh yang menetap.
- Carousel tidak berpindah bila seluruh item sudah muat, misalnya tiga review pada desktop. Ini tidak menandakan kegagalan.

Validasi tambahan: 71 tes unit, TypeScript, dan lint file yang disentuh lulus. Build production server berhasil. Uji browser candidate lulus pada 375/768/1024/1440 px tanpa overflow; opt-in reduced motion, hover scale, autoplay kedua carousel, persistensi, reset, dan tidak adanya error JS terverifikasi. Screenshot desktop/mobile diperiksa. Service setelah aktivasi berstatus active dan Nginx mengembalikan HTTP 200. Temuan lint seluruh proyek yang dicatat di bawah tetap di luar lingkup. Catatan “validasi visual belum selesai” di bagian historis bawah sudah digantikan hasil tambahan ini.

Verifikasi setelah aktivasi melalui tunnel ke Nginx juga lulus: empat lebar Beranda, kontrol motion dan autoplay, navigasi Tentang Kami/Kontak/Katalog tanpa overflow pada mobile, serta kode unit detail memakai monospace. Ketujuh aset JS/CSS yang dirujuk HTML Beranda mengembalikan HTTP 200. Ini pengujian Chromium dengan emulasi preferensi, belum pengujian langsung Zen Linux.

Tanggal: 29 Oktober 2026. Arah: kohesif, techy, tetap mencerminkan identitas perusahaan. Referensi visual utama: gambar Beranda LSP Informatika yang diberikan pengguna.

## Cakupan dan batas bukti

Audit implementasi mencakup CSS global, Beranda, komponen heading dan kartu, font root layout, internal hero, halaman Tentang Kami, serta katalog skema. Perbandingan eksternal memakai konten situs resmi yang dapat diakses. Gambar referensi memberi bukti visual LSP Informatika; situs lain hanya dinilai struktur informasi dan fitur yang terbaca, bukan kualitas visual, aksesibilitas, kecepatan, atau keberhasilan konversinya. Tidak ada skor numerik yang mengesankan pengukuran tersebut sudah dilakukan.

## Arah desain

Pertahankan logo, Figtree, biru utama #004195, biru pendukung #1576b5, cyan #84d3eb, putih, serta latar terang #f4f7f7. Gunakan navy sebagai permukaan pendukung hero; warna cyan untuk aksen kecil pada permukaan gelap. Nuansa techy dibangun lewat ketelitian tipografi, grid, ikon seragam, serta penyajian data yang rapi. Foto perusahaan dan bukti legalitas menjaga karakter institusi.

Jangan menyalin klaim AI, angka layanan, atau identitas lembaga lain. Hindari menambah dekorasi terminal, neon, atau simbol kode yang tidak membantu calon peserta.

## Tipografi dan opsi Nerd Font

| Peran | Rencana |
| --- | --- |
| Hero Beranda | Figtree 700, 36–60 px, line-height 1.12, pembungkusan alami |
| Judul halaman internal | Figtree 700, 32–48 px, line-height sekitar 1.15 |
| Judul section | Figtree 700, 24–32 px, line-height 1.25 |
| Judul kartu | Figtree 600–650, 18–20 px, line-height 1.35–1.4 |
| Pengantar | Figtree 400, 16–18 px, line-height 1.6–1.65 |
| Isi | Figtree 400, 16 px, line-height 1.6–1.75, lebar sekitar 45–75 karakter |
| Label/metadata | Figtree 500–600, 14 px dengan kontras cukup |
| Kode teknis | Monospace 13–14 px untuk kode skema/unit atau nomor sertifikat; sediakan tombol salin bila dibutuhkan |

Nerd Font adalah opsi untuk kode teknis, bukan pengganti Figtree. Rekomendasi desain: mulai dengan monospace terbatas; pertahankan Heroicons untuk ikon UI. Belum memasang font baru. Jika memilih Nerd Font, evaluasi lisensi, ukuran aset, subset, fallback, dan keterbacaan kode panjang. Simbol ikon tidak boleh menjadi satu-satunya nama kontrol. Angka statistik cukup memakai tabular numerals.

## Urutan pelaksanaan lanjutan

1. **Fondasi:** tetapkan token semantik heading, body, metadata, warna, border, radius, spacing dan focus. Konsolidasikan aturan komponen; hapus font tidak terpakai setelah pemeriksaan rute.
2. **Perjalanan Beranda:** uji hero dan frame pada 375, 768, 1024, dan 1440 px; evaluasi penempatan akses skema, alur asesmen, dan pendaftaran. Heading harus tetap dominan dengan konten CMS yang panjang.
3. **Katalog dan detail:** samakan judul, metadata, filter, tombol, harga, persyaratan, dan urutan informasi. Terapkan monospace hanya pada kode teknis bila contoh visualnya membantu pemindaian.
4. **Halaman institusi:** samakan internal hero, section heading, dokumen legalitas, kontak, dan footer. Pertahankan foto dan logo asli sebagai pembawa identitas.
5. **Validasi:** cek desktop/mobile, keyboard dan focus, zoom 200%, kontras, kondisi kosong/gagal, reduced motion, serta pencarian dan tautan tindakan. Bandingkan screenshot lintas rute sebelum menyatakan sistem kohesif.

Selesai bila peran tipografi konsisten, tidak ada overflow pada lebar uji, informasi utama dan langkah berikutnya mudah ditemukan, serta fitur dan klaim sesuai data. Audit lanjutan tidak otomatis berarti seluruh redesign lintas halaman sudah diimplementasikan.
