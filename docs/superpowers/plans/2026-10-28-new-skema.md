# Pembaruan Skema Oktober 2026 Implementation Plan

> **For agentic workers:** Gunakan superpowers:executing-plans untuk implementasi langkah demi langkah.

**Goal:** Memasukkan 15 skema dari `New Skema.md` ke database server SSH, memperbarui record lama yang sama/mirip dan menambahkan gambar relevan.

**Architecture:** Import berbasis manifest dengan pemetaan ID eksplisit, dry-run, transaksi database, serta backup dan rollback. Pembaruan mempertahankan ID dan slug lama agar URL dan referensi halaman tetap berfungsi.

**Tech Stack:** Laravel 13, Eloquent, Artisan, storage public, SSH.

**Spec:** `New Skema.md` dan instruksi pengguna pada 28 Oktober 2026.

- Jenis kosong pada entri 12 dan 13 diisi Okupasi berdasarkan bentuk jabatan. Chief → Lead Data Scientist memakai ID 26 dengan lima dari tujuh kode unit sama. Supervisor Mobile tetap ditambah terpisah.

- Backup penuh server: `/var/backups/lsp-global/new-schemes-20261028/database.sql.gz` dan `public-storage.tar.gz`. Journal sebelum/sesudah batch: `backend/storage/app/private/scheme-imports/new-schemes-20261028/` di server.
- Rollback: jalankan sebagai deploy dari backend, `php artisan content:import-new-schemes --rollback`. Perintah menolak bila record batch atau halaman sudah berubah; periksa perubahan berikutnya sebelum memulihkan backup penuh. Kegagalan apply sebelum commit juga dapat dibersihkan dengan rollback hanya jika snapshot seluruh database skema/halaman masih sama.
- Tes backend terkait: 35 lolos, 405 assertions. Review importer dan perbaikan recovery selesai tanpa blocker.
- Temuan verifikasi frontend: level null diterbitkan API sebagai 0 dan sebelumnya tersaring dari katalog. Perbaikan menampilkan level tak diketahui pada rentang default, menaruhnya terakhir pada urutan level, dan menampilkan label level/metode belum ditetapkan. Tes frontend: 70 lolos; lint pada file berubah dan TypeScript lolos.
- Patch deployment frontend disusun terhadap sumber server untuk mempertahankan penyesuaian basePath dan public-image. Build dilakukan terpisah dari aplikasi aktif; Turbopack menolak symlink node_modules di luar root sehingga build memakai webpack.

- Build webpack server berhasil dan service `lsp-global-staging-frontend.service` aktif kembali. Build sebelumnya tetap tersedia di `/var/www/lsp-global-staging/frontend/.next.before-new-schemes-20261028`; sumber tiga file sebelum patch ada di backup `frontend-source-before.tar.gz`.
